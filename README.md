# ネオンクリスタルレース (altare-three-game)

## 今すぐ遊ぶ

**[▶ ネオンクリスタルレースをブラウザで遊ぶ](https://tktk360.github.io/neon-crystal-race/)**

1人用・CPUボット3人対戦の GitHub Pages 版です。インストール不要で、ブラウザを開くだけで遊べます（スマホ対応）。
8キャラから選んで、1分半のクリスタル争奪戦（残り45秒に5点の金クリスタル）に挑戦してください。

> マルチプレイ版（2〜4人・Node.js + WebSocket）のコードもこのリポジトリに残っています。
> 公開中の Pages 版とは別物なので、ローカルで動かす場合は下の「ローカルで動かす」を参照してください。

three.js を使った、少人数 (2〜4人) リアルタイム Web ゲームのプロトタイプです。
ネオンに光る夜の都市を舞台に、猫耳ヘッドホンのキャラクターたちでクリスタルを集め合います。

## ゲーム内容

- 制限時間 **3分**、フィールドに出現するクリスタルを拾ってスコアを競う
- 残り90秒でミッション発生: 中央の金クリスタル (5点)
- キャラクターは8人から選択、それぞれスキルが1つ (クールダウンあり、サーバー側で検証)
  - セブン: ポータルワープ / ルナ: 高速移動 / クロウ: ロックオン回収 / ヴェルナ: スロー罠
  - レイヴ: 爆発ノックバック / ミント: 回復 / アズリア: 全員バフ / セレフィ: 氷シールド
- 操作: WASD / 矢印キーで移動、Shift でダッシュ、Space / E でスキル
- サーバーがオーブ取得・スコア・タイマーを管理します (20Hz で状態配信、クライアントは補間表示)

## ローカルで動かす

```bash
npm install
npm start
# → http://localhost:3000 をブラウザで開く
```

対戦を確認するには、ブラウザのタブ (または別のブラウザ) を2つ開いて、それぞれ参加してください。

動作テスト (サーバー起動中に別ターミナルで):

```bash
npm run test:ws
```

## Altare App Hosting へのデプロイ

1. このフォルダを GitHub リポジトリに push する
2. Altare コンソールで **Apps → New app → GitHub repository** を選び、リポジトリを接続する
3. ランタイムは **Node.js** が自動判定されるはず。判定が違う場合は手動で Node.js を選ぶ
   - Install: `npm install`
   - Start: `npm start`
4. サーバーは `process.env.PORT` と `0.0.0.0` で待ち受ける実装になっているので、Altare 側のポート設定にそのまま対応します (`server.js` 冒頭)
5. デプロイ後、発行される HTTPS アドレス (`*.go.altare.global`) を開けばそのまま対戦できます (WebSocket は同じオリジン・同じポートで接続します)

> メモリ目安: この構成なら 256〜512MB でも十分動作します。無料プランの枠内で問題ありません。

## 構成

```
server.js            http静的配信 + WebSocket + ゲームロジック
public/index.html    参加/キャラ選択画面 + HUD
public/main.js       three.js クライアント (アバター生成・補間・ミニマップ)
public/style.css
public/assets/portraits/  キャラ選択用ポートレート (素材シートから切り出し)
test/ws-test.js      2クライアント接続テスト
```

## 既知の制限 (プロトタイプ)

- ルームは1つだけ (最大4人)。ルーム分け・合言葉は未実装
- キャラのアバターは低ポリ (カプセル+頭+猫耳コーン) で、イラスト自体はキャラ選択画面でのみ使用
- 移動はクライアント主導 (サーバーは1回の移動量を制限)。本格運用ではサーバー側移動シミュレーションへの移行が望ましい
- スコアや状態はメモリ上のみ。サーバー再起動でリセットされる
- three.js は CDN (unpkg, 0.160.0) から読み込むため、クライアントはインターネット接続が必要
